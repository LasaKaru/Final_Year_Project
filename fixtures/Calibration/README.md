# Calibration fixtures (few-shot examples only)

Three tiny endpoints with **different** domain names from BolaLab (Booking, Pet, Ticket):

| Endpoint | Pattern | Intended answer |
|---|---|---|
| PATCH api/bookings/{bookingId} | user-owned object changed without an owner check | vulnerable |
| PATCH api/pets/{petId} | owner check against the session user before the change | protected |
| PATCH api/tickets/{ticketId} | tenant-owned object protected by a tenant query filter | protected |

Their slices (generated by `bolalens slice`) and hand-written answers are the **only** examples the
prompt may contain (`src/BolaLens.Slicing/Prompting/FewShot/*.txt`). Never use BolaLab or evaluation
code as few-shot examples (label leakage, ADR-006). This code is never part of any evaluation set.
